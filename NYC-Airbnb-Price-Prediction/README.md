# NYC Airbnb Price Prediction

A separate AIML Minor Project 2 inside the Cars EDA repository.

## Notebook
`NYC_Airbnb_Linear_Regression_Project.ipynb` covers EDA, missing-value handling, outlier treatment, one-hot encoding, an 80:20 split, linear regression, evaluation metrics and residual analysis.

## Run
Open the notebook in Google Colab or Jupyter and run all cells. It loads the AB_NYC_2019 dataset from a public CSV source.
