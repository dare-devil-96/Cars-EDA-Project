# Cars EDA Project

This is my Exploratory Data Analysis (EDA) project on a used cars dataset.

## About

The aim is to understand the dataset, check its quality, explore patterns and present useful findings through visualisations.

The notebook includes:
- Dataset loading and initial inspection
- Missing value and duplicate checks
- Basic data cleaning
- Summary statistics
- Brand and fuel type analysis
- Price and distance analysis
- Outlier detection using the IQR method
- Correlation and multivariate analysis
- Final findings and observations

## Dataset

The analysis uses `UsedCars_Combined.csv` from the used cars dataset downloaded from Kaggle. The dataset file is not included here; download it from the source and upload it when running the notebook.

## Tools

Python, Pandas, NumPy, Matplotlib, Seaborn and Google Colab.

## Running the notebook

1. Download the dataset ZIP from its Kaggle source.
2. Open `Cars_EDA_Project.ipynb` in Google Colab.
3. Upload the ZIP file when prompted.
4. Run the cells from top to bottom.

The notebook reads `UsedCars_Combined.csv` from the extracted `cars_dataset` folder.

## Project

This project was completed as an individual EDA assignment. It focuses on exploring the data and explaining patterns; no machine-learning model is used.
